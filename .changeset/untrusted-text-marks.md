Text from the agent no longer reads as something other than what runs or opens. A command and its `cwd` in `ApprovalCard`, and a file path, a diff line and a renamed file's note in `DiffReview`, show characters that do not show as a mark with their code points: a bidi override (`U+202E`) in a path no longer shows the end of it reversed, so `notes` + U+202E + `txt.sh` no longer looks like a text file, a Trojan Source line no longer reads as a comment, and zero-width spaces, Unicode tags and control characters such as an ANSI escape are visible. A command now wraps instead of scrolling sideways, so what comes before its end, such as 240 spaces before `--script-shell=./x.sh`, cannot push that end out of view. A command or a path also shows a run of spaces 16 columns wide or more as its count, and spaces other than U+0020 by their code points. The joiners and variation selectors inside an emoji are left as they are. A Markdown link whose text names another host than the one it goes to (`[https://github.com/…](https://evil.example/login)`), or names it in look-alike letters, or whose URL puts a name before the host (`https://github.com@evil.example`), shows the host it goes to beside it, and its accessible name says so. `Sources`, file attachments in `AgentMessage` and Markdown link only to http, https, mailto and relative URLs, and files to `data:` and `blob:` too: a `javascript:` URL renders as text, with React 18 as well, which renders such a link as it is. `revealText` and `safeUrl`, which do this, are exported from `signoff-ui/core` for your own previews. The labels gain an `untrusted` section for the marks' names (`invisible`, `blank` and `linksTo`): a translation typed as `SignoffLabels` needs those three to type-check, and one passed as `SignoffLabelsInput` keeps the English for them.
